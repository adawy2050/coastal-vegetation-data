# Coastal vegetation data

Display polygons, polygon-to-grid links and selected daily FORA–JPN60 surface cell histories (1998–2020) for the Coastal Vegetation portal. Habitat polygons use provisional species candidates and are simplified for display; the source GIS remains authoritative. FORA–JPN60 was developed by JMA/MRI and JAMSTEC under MEXT SENTAN grant JPMXD0722680734. Data policy: https://www.jamstec.go.jp/fora/e/datause.html. Currents retain cm/s and shortwave is net surface radiation. Source credits and interpretation are provided in the portal.
